# Ignyous Bridge WordPress Plugin

Connects your WordPress site to the Ignyous AI platform for powerful AI-driven site management and optimization.

## Installation

1. Download `ignyous-bridge.zip`
2. Go to WordPress Admin → Plugins → Add New → Upload Plugin
3. Upload the zip file and activate
4. Go to Settings → Ignyous Bridge to verify connection

## Requirements

- WordPress 5.0+
- PHP 7.4+
- REST API enabled

## Features

- One-click connection to Ignyous AI platform
- Automatic site scanning
- API key generation and management
- Secure REST API endpoints
- Plugin and theme management via API
